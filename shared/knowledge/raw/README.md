# Raw Knowledge Sources

`raw/` stores immutable copies of original source material before processing or synthesis.

## Categories

- `articles/`
- `videos/`
- `transcripts/`
- `repos/`
- `documents/`
- `notes/`
- `datasets/`
- `assets/`

## Rules

- Preserve original content and provenance.
- Never overwrite, normalize in place, or silently repair an existing raw item.
- Add corrections or newer versions as new items with distinguishable names.
- Keep derived summaries and analysis out of `raw/`; place them in `../sources/` or `../wiki/`.
- Do not copy operational project state from `../../projects/` into raw knowledge.
- Record access or licence constraints in the corresponding source card when known.
