# LLM Wiki

`wiki/` contains living synthesized Markdown knowledge.

## Categories

- `concepts/`: durable ideas and definitions.
- `technologies/`: technology-specific knowledge.
- `tools/`: tool behavior and usage knowledge.
- `projects/`: durable project knowledge that is not current operational state.
- `research/`: synthesized research findings.
- `comparisons/`: evidence-backed comparisons.
- `architecture/`: reusable architecture knowledge.
- `decisions/`: durable knowledge decisions and rationale, not active project approvals.
- `patterns/`: reusable patterns and anti-patterns.
- `glossary/`: shared terminology.

## Rules

- Follow `../SCHEMA.md`.
- Update an existing relevant page instead of creating avoidable duplicates.
- Preserve links to supporting source cards.
- Mark conflicts, uncertainty, provisional conclusions, and stale evidence explicitly.
- Never copy current TODOs, blockers, handoffs, approvals, or workflow status from `../../projects/`.
- Update `../index.md` whenever pages are added, renamed, moved, or removed.
